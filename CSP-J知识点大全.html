一、计算机基础与初赛常识

1.1 计算机发展史与冯·诺依曼体系

五代计算机：第一代(1946–1958，真空电子管)、第二代(1959–1964，晶体管)、第三代(1965–1970，集成电路)、第四代(1971–1980，大规模/超大规模集成电路)、第五代(现代，智能计算机系统)。

  • ENIAC(1946，宾夕法尼亚大学)：第一台电子计算机，使用真空电子管。
  • EDVAC：第一台具存储功能的计算机，由冯·诺依曼提出“存储程序”原理设计。
  • 冯·诺依曼架构五大部件：运算器、控制器、存储器、输入设备、输出设备。核心思想——指令与数据均存于内存，由控制器统一调度（“存储程序”）。

关键人物：冯·诺依曼(体系结构/计算机之父)、图灵(图灵机/图灵测试)、香农(信息论)、麦卡锡(人工智能奠基)、洛夫莱斯(首位程序员)。图灵奖由 ACM 于 1966 年设立，是计算机界最高奖；姚期智是迄今唯一华人得主。

计算机分类：按规模→巨型/大型/中型/小型/微型(PC)；按用途→专用/通用；按原理→模拟(连续信号)/数字(离散信号)；按功能→单媒体/多媒体。

五大特征：运算快、精度高、存储强、逻辑运算强、自动控制强。五大应用领域：数值计算(最早)、数据处理(最广泛)、过程控制、计算机辅助系统(CAD/CAM/CAI/CAT)、人工智能。

1.2 硬件系统

计算机系统 = 硬件(物质基础) + 软件(灵魂)。未装任何软件的计算机称裸机。

  • CPU = 运算器(ALU，执行加减乘除与逻辑比较) + 控制器(取指令、发信号，不存数据) + 寄存器(最快最小存储单元)。
  • 存储器：主存(内存，易失、断电丢失、CPU 直连) vs 辅存(外存，非易失，如 SSD/HDD/U盘/光盘)。内存以字节(Byte)为单位，每单元有唯一十六进制地址。
  • Cache(高速缓冲存储器)：位于 CPU 与内存之间，提升数据访问速度。
  • 总线三类：数据总线 DB(双向)、地址总线 AB(单向，送地址)、控制总线 CB(传递控制信号)。
  • 四大性能指标：字长(CPU 一次处理的二进制位数)、内存容量(GB)、主频(时钟频率)、运算速度(单位 MIPS，每秒百万条指令)。

1.3 软件系统与编程语言

软件分类：

  • 系统软件：操作系统(最核心，裸机上的第一层)、语言处理程序(如 C++ 编译器)、DBMS(数据库管理系统)、辅助程序(诊断/反病毒/备份等)。
  • 应用软件：文字处理(WPS/Word)、办公(MIS)、CAD、图形(Photoshop)、教育、游戏等。依赖系统软件，不能独立运行。

常见操作系统：Windows、macOS(基于 UNIX)、Linux/UNIX(服务器)、iOS/Android/鸿蒙(手机)。

计算机语言层级：

  • 机器语言：二进制 0/1，CPU 唯一可直接执行，快但难读。
  • 汇编语言：用助记符(ADD/MOV)替代二进制，需翻译。
  • 高级语言(C++/Python/Java)：独立于硬件。分编译型(C/C++，先整体编译为机器码，效率高、跨平台差)与解释型(Python/JS，逐句翻译，跨平台好、效率较低)。

常见文件后缀：.exe(可执行)、.docx/.pdf(文档)、.jpg/.png(图片)、.mp3(音频)、.zip(压缩)、.mp4(视频)。

1.4 信息编码与存储

编码：将字符/数值转为二进制(外码→内码→存储)；解码为其逆过程。

  • ASCII：7 位，128 字符(0–127)；存储占 1 字节(8 位，最高位 0)；扩展 ASCII 最高位 1(128–255)。
  • GB2312：双字节汉字编码，可编码 2⁷×2⁷=16384 个汉字及符号。
  • 字形码：汉字点阵(如 16×16)，每点 1 bit，共 256 点需 32 字节。
  • Unicode/UTF-8：Unicode 收录超 100 万字符(前 128 兼容 ASCII)；UTF-8 变长——ASCII 1 字节、常用汉字约 3 字节、生僻字最多 4 字节。互联网主流编码。

存储单位：1 bit=1 位；1 Byte=8 bit；1KB=1024B；1MB=1024KB；1GB=1024MB；1TB=1024GB。int 典型范围 −2³¹ ~ 2³¹−1 (−2147483648 ~ 2147483647)。

图片空间 = 宽×高×位深度÷8（字节）
视频空间 = 单帧大小×帧率×时长 或 (视频码率+音频码率)×时长

1.5 计算机网络

  • 定义：通过通信线路连接多台异地计算机的系统。通信必须遵循协议，核心是 TCP/IP 协议族。
  • 发展史四阶段：萌芽(ENIAC/SAGE) → 诞生(1969 ARPANET) → 标准化(ISO 制定 OSI，TCP 可靠传输+IP 寻址) → 全球互联(1986 NSFNET，1994 中国正式接入互联网)。
  • 分类：按地理→LAN(≤1000m)/MAN/WAN；按介质→有线(光缆/同轴/双绞线)/无线(WiFi/蓝牙)；按拓扑→星型/总线/环/树/网状。
  • 体系结构：OSI 七层(物→数链→网→传→会→表→应，理论标准)；TCP/IP 四层(网接口→网→传→应，事实标准)。
  • 核心协议：TCP(面向连接、可靠)、IP(寻址路由)、UDP(快、不可靠)、DNS(域名→IP)、DHCP(自动分配 IP)、HTTP(网页)、FTP(文件)、SMTP(发邮件)、POP3/IMAP(收邮件)、ARP(IP→MAC)。WWW 是集合而非协议；URL 是资源定位符。
  • IPv4：32 位，点分十进制。A 类(1–126，首位0)、B 类(128–191，前两位10)、C 类(192–223，前三位110)、D 类(224–239，多播)、E 类(240–255，保留)。IPv6：128 位，冒分十六进制，支持零压缩。
  • 子网掩码：32 位，区分网络位与主机位；网络/广播地址不可分配给主机。
  • 域名：主机名.二级域名.顶级域名(如 docs.www.example.com)；≤255 字符，不区分大小写。
  • HTML：超文本标记语言。常用标签 <html><head><title><body><h1><p><img>，<meta charset="UTF-8"> 设编码。

1.6 计算机安全与病毒

三大维度：硬件安全(温湿度/物理防护)、存储安全(病毒/非法访问/辐射/硬件损坏)、数据安全。

病毒六大特征：繁殖性(自我复制)、破坏性、传染性、潜伏性、隐藏性、可触发性。

三、进制与位运算

3.1 进制基础

进位计数制核心是“逢 X 进一”，X 即基数(可用数码个数)。位权=基数的幂次：个位 X⁰、十位 X¹、小数点后 X⁻¹…… 任意进制可展开为多项式，如 256.47₁₀ = 2×10²+5×10¹+6×10⁰+4×10⁻¹+7×10⁻²。

编程前缀：二进制 0B、八进制 0、十进制无前缀、十六进制 0X。例：0B10000、020、16、0X10 都等于十进制 16。

printf 格式符：%d(十进制)、%o(八进制)、%x(十六进制)、%f/%lf(浮点)。bitset<8> 可将整数转 8 位二进制串(如 16→00010000)。

3.2 进制互转

转换方法要点
X 进制 → 十进制按权相加法各位数码×位权后求和。如 10110₂=1×2⁴+0+1×2²+1×2¹+0=22
十进制整数 → X 进制短除法(除X取余)不断÷X 记录余数，逆序排列
十进制小数 → X 进制乘X取整法不断×X 取整数，正序排列
二进制 ↔ 八进制三位分组法(421法)从右向左每 3 位一组，不足左补 0
二进制 ↔ 十六进制四位分组法(8421法)从右向左每 4 位一组，不足左补 0；A–F 表 10–15
8421 法实质是二进制位权(8,4,2,1)口诀化：把十进制数拆成这些位权之和，对应位填 1。如 22 = 16+4+2 → 10110₂。

十六进制字母含义：A=10, B=11, C=12, D=13, E=14, F=15（用字母避免多位数字位混淆，如 32F 不会误读）。

3.3 小数进制与位运算

小数互转：二进制小数 0.101₂ = 1×2⁻¹+0×2⁻²+1×2⁻³ = 0.625。二进制小数转八/十六进制：小数部分从左到右三位/四位一组、末尾补零，用 421/8421 法。十进制小数转二进制用“乘二取整、正序排列”(区别于整数的除二取余)。

位运算：二进制补码表示负数——先取反再加 1，最高位为符号位。运算符优先级：~ > << >> > & > ^ > |，务必显式加括号。

四、排列组合与计数

  • 加法原理(分类)：各类方法互斥，总方案=各类之和(北京→上海 3+4+7+2=16 种)。
  • 乘法原理(分步)：每步独立且必执行，总方案=各步之积(2 件 T 恤×3 条裤子=6 种)。

排列 A(n,r)：从 n 个选 r 个并排序，A(n,r)=n×(n-1)×…×(n-r+1)=n!/(n-r)!。顺序不同算不同方案。

组合 C(n,r)：只选不排，C(n,r)=A(n,r)/r!=n!/[r!(n-r)!]。AB 与 BA 视为同一方案。核心判据：关注“谁和谁一组”(组合)还是“谁先谁后”(排列)。

组合恒等式：对称性 C(n,r)=C(n,n-r)；递推 C(n+1,r)=C(n,r)+C(n,r-1)。递推数组 C[i][j]=C[i-1][j-1]+C[i-1][j] 即杨辉三角(第 n 行第 r 项=C(n,r))，是 DP 求组合数的基础。

六大计数技巧：

  1. 特殊优先法：先安排受限元素(如“甲乙不能站头尾”)。
  2. 捆绑法：必须相邻者捆成一整体先排，再排内部(7 人甲乙相邻→A(6,6)×A(2,2)=1440)。
  3. 插板法：N 个相同元素分 R 组，每组≥1→C(N-1,R-1)；可空组→C(N+R-1,R-1)。
  4. 可重复排列：N 元取 R 个允许重复→N^R。
  5. 小球盒子：N 同球入 R 异盒，非空→C(N-1,R-1)，可空→C(N+R-1,R-1)；指定数量→N!/(n₁!n₂!…nᵣ!)。
  6. 万能枚举：公式忘或情形复杂时，小规模直接穷举保底。

五、数论基础

5.1 整除、奇偶与约数

自然数=非负整数(0,1,2,…)；整数=自然数+负整数。奇/偶由能否被 2 整除判定(a%2==1 奇，a%2==0 偶)。若 A×Q=B 则 A∣B(整除)；A 是 B 的约数，B 是 A 的倍数。求 X 的所有约数：枚举 i 到 √X，i 与 X/i 成对存入。

5.2 最大公约数 GCD（欧几里得算法）

GCD(a,b) 是能同时整除 a,b 的最大正整数。原理：GCD(a,b)=GCD(b, a mod b)，a>b。迭代：循环 a←b, b←a%b 直到 b=0，此时 a 即 GCD；递归 b?gcd(b,a%b):a。

5.3 最小公倍数 LCM

LCM(a,b) = a×b ÷ GCD(a,b)。例 LCM(36,24)=72。

5.4 同余

若 m∣(a−b)，则 a ≡ b (mod m)，即 a%m==b%m。三大性质：自反(a≡a)、对称(a≡b⇒b≡a)、传递。运算律：加减乘同余保持(a±c≡b±d, ac≡bd)；除法需 k 与 m 互质。应用——大数取模“边算边取余”n=(n*a)%7 防溢出；星期推算算 a^b mod 7。

5.5 质数、合数、算术基本定理与筛法

  • 质数：>1 且仅 1 与自身两个正约数(2,3,5,7)；合数：>1 且有其他约数；1 既非质数也非合数。判定只需试除到 √n。
  • 算术基本定理：n>1 可唯一分解为 n=p₁^e₁·p₂^e₂·…·pₖ^eₖ。
    约数个数 d(n)=(e₁+1)(e₂+1)…(eₖ+1)；约数和 σ(n)=(1+p₁+…+p₁^e₁)(1+p₂+…+p₂^e₂)…。例 30=2¹·3¹·5¹ ⇒ d(30)=8，σ(30)=72。
  • 埃氏筛：从 2 起筛去其倍数，复杂度 O(n log log n)。
  • 线性筛(欧拉筛)：O(n)，每个合数仅被最小质因数筛一次。遍历 primes，筛 i×primes[j]；若 primes[j] | i 则 break。

六、数据结构

6.1 STL 容器（C++ 标准模板库）

STL 三大组件：容器(管理数据)、算法(处理数据)、迭代器(访问元素，前闭后开 [begin, end))。

容器特点常用复杂度/函数
vector动态数组，内存连续，尾部增删高效，中间慢push_back/pop_back/insert/erase；reserve(预分配)/resize(改元素数)
array定长顺序表，编译期定大小，不可扩容at() 越界检查；operator= 整体赋值
deque双端队列，两端 O(1)，支持随机访问push_front/pop_front + push_back/pop_back
list双向链表，任意位置增删 O(1)，不支持下标sort()/unique()/merge()
set/multiset有序(红黑树)，自动排序去重；multiset 允许重复insert/find/count/lower_bound/upper_bound，O(log n)
map/multimap键值对，按键排序；multimap 键可重复[] 改 value、find、count、insert
unordered_*哈希实现，无序但查找平均 O(1)专注存在性判断
stack适配器，后进先出 LIFOpush/pop/top，无迭代器
queue适配器，先进先出 FIFOpush/pop/front/back
priority_queue堆，默认大根堆(顶为最大)top/push/pop；可指定 greater 转小根堆
迭代器：vector 为随机访问(支持 ±整数、相减)；list 仅双向(++/--)。set/map 的 key 不能直接修改，需先 erase 再 insert。stack/queue/priority_queue 无迭代器，操作前必查 empty()。

6.2 栈与队列

栈：后进先出(LIFO)，push/pop/top。队列：先进先出(FIFO)，push/pop/front/back。二者均为操作受限的线性结构，常作为算法辅助。

6.3 树与二叉树

树：非线性层次结构。N 节点→N-1 条边；唯一根(无前驱)；子树独立(不能跨子树连边)。

  • 术语：节点度(子节点数)、树度(最大度)、叶子(度0)、分支节点(度≥1)、祖先/子孙/父/子/兄弟、路径。
  • 高度/深度/层：深度=根到该节点边数(根0)；层=深度+1；高度=节点到最远叶子边数(叶子0)。树高=根高，树宽=最多节点的那一层节点数。
  • 二叉树：每节点最多两个孩子(左/右有序，不可交换)。五形态：空/仅根/根+左/根+右/根+左右。
  • 满二叉树：除叶子外均有两孩子；深度 N 时共 2^N−1 节点。
  • 完全二叉树：除最下两层外全满，底层靠左连续。性质：第 i 层最多 2^(i-1) 节点；n 节点层数=⌊log₂n⌋+1；叶子数 N₀ = 度为2节点数 N₂ + 1。
  • 数组存储(下标从1)：节点 i 的左孩子 2i、右孩子 2i+1、父 ⌊i/2⌋。

四种遍历：层序(BFS，上→下、左→右)、前序(根→左→右)、中序(左→根→右)、后序(左→右→根)。

已知中序+后序可推前序；已知前序+中序可推后序；但仅凭前序+后序无法唯一确定二叉树(缺左右边界信息)。

七、算法思想

7.1 递归与递推

递归：函数调用自身，必须含终止条件与递推关系。例：等差数列 f(n)=f(n-1)+3, f(1)=1；斐波那契 F(n)=F(n-1)+F(n-2), F(1)=F(2)=1。

递归的缺陷：斐波那契递归有大量重复子问题，时间复杂度 O(2ⁿ)，N=50 时卡死。递推(自底向上、数组存中间结果、for 循环)降到 O(n)，且用 long long 防溢出。例：堆叠方块 level[i]=level[i-1]+i。

7.2 分治与二分查找

分治：“分而治之”，把大问题分解为同结构子问题。二分查找是分治最典型应用，前提数组有序，每次排除一半，复杂度 O(log n)。

int l=0, r=N-1, pos=-1;
while(l <= r){
    int mid=(l+r)/2;
    if(A[mid]==X){ pos=mid; break; }
    else if(A[mid]>X) r=mid-1;
    else l=mid+1;
}
// 退出循环即未找到(pos 仍为 -1)

边界关键：l > r 是唯一未找到的终止信号。下标从 0 开始，输出位置常需 +1。

7.3 快速排序

分治排序：选基准值 → 双指针分区(≤基准 / >基准) → 递归子区间。平均 O(n log n)。

void quick_sort(int l, int r){
    if(l >= r) return;
    int p = A[(l+r)/2];   // 缓存基准，防交换覆盖
    int i=l, j=r;
    while(i <= j){
        while(A[i] < p) i++;
        while(A[j] > p) j--;
        if(i <= j){ swap(A[i],A[j]); i++; j--; }
    }
    if(l < j) quick_sort(l, j);
    if(i < r) quick_sort(i, r);
}

7.4 贪心算法

每步选当前最优，期望局部最优→全局最优。前提：局部最优能保证全局最优(需验证)。

  • 找零问题：面额 1/5/11 凑 11 元，贪心(先 11→再 1×0，共 1 张……此处贪心恰可)但若凑 15 元贪心得 11+1×4=5 张，而最优是 3 张 5 元——说明贪心在非规范硬币系统会失效。
  • 排队打水：R 个水龙头、N 人打水，时间短者优先可使总耗时最小。先 sort 升序，第 i 人总耗时=自身时间+第(i−R)人时间(递推)。
贪心 vs DP：贪心只做即时最优、不回溯；DP 依赖子问题复用与最优子结构。硬币找零(1/5/11)正是用 DP 而非贪心。

7.5 动态规划（DP）

核心思想：用小问题最优解构建大问题最优解(分而治之+记忆复用)。三特征：重叠子问题、最优子结构、无后效性。五步法：①识别重叠子问题与最优子结构 ②定义最小状态 ③明确状态物理意义 ④推导转移方程 ⑤初始化+填表+取答案。

经典模型状态定义转移方程
硬币最少枚数dp[j]=凑出 j 的最少硬币dp[j]=min(dp[j], dp[j−coin[i]]+1)
最长不下降子序列 LISdp[i]=以 i 结尾的最长长度dp[i]=max(dp[j]+1)，j<i 且 A[i]≥A[j]
前缀最大值和dp[i]=前 i 个最大值dp[i]=max(dp[i-1], a[i])
最大子数组和dp[i]=以 i 结尾的最大和dp[i]=max(dp[i-1]+a[i], a[i])
数塔dp[i][j]=从(i,j)到底最大和dp[i][j]=tower[i][j]+max(dp[i+1][j],dp[i+1][j+1])
零一背包dp[i][j]=前 i 件、容量 j 最大价值dp[i][j]=max(dp[i-1][j], dp[i-1][j−t]+w)
完全背包同左(可无限取)用 dp[i][j−t]+w(同一物品可再选)

背包滚动数组优化：零一背包一维 F[j]，内层逆序遍历(防重复取)；完全背包正序遍历(允许重复取)。记忆化搜索是 DP 的递归实现(DFS+缓存)。

初始化技巧：dp 数组初值常设为“不可达”标记(如 target+1)，最终若仍为初值说明无解，输出 −1。

7.6 搜索：DFS / BFS / 回溯

DFS(深度优先)：“一条道走到底，不撞南墙不回头”，递归天然支持回溯。要点：递归参数(坐标/步数)、访问标记(防重复/死循环)、边界判断、方向数组 dx/dy。迷宫路径问题：到终点统一打印路径，用 exit(0) 快速返回首条路径。

BFS(广度优先)：按层扩展，首次到达终点即最短路径。可用二维数组+head/tail 模拟队列；方向数组统一四向探索；记录前驱(parent)可递归回溯输出正向路径。

回溯 = DFS + 状态回退：找到一条路径后不终止，撤销当前标记(mark[x][y]=false)、清理路径数组，继续探索剩余方向。误区：回溯是“接着上次方向继续”，而非“重新从右开始”。

八、高精度运算

C++ 内置类型有上限：int ~±2×10⁹，long long 最多精确 19 位十进制。超出范围必须用高精度：字符串输入 → 逆序转数组 → 模拟竖式 → 进位/借位 → 逆序输出。

通用框架：①逆序存储(个位在 A[0]，如 "789"→A=[9,8,7])；②字符转数字 c-'0'；③数组初始化为 0、长度预留冗余(如 210)；④进位/借位；⑤输出前跳前导零。
  • 加法：逐位相加暂存，再从低到高统一进位(A[i]>=10 → A[i+1]+=A[i]/10; A[i]%=10)。结果最多比原数多 1 位。
  • 减法：先比大小保证大减小，否则交换+补负号；借位 a1[i+1]--; a1[i]+=10。
  • 乘法×单精度：逐位乘 B，再统一进位(循环 S.size()+4 次)。
  • 乘法×高精度：双重循环 C[i+j]+=A[j]*B[i](错位累加)，结果位数≤两数位之和(开 500)。
  • 除法÷单精度：从高位逐位试商，余数 t 串联(t=t*10+位; 商=t/B; t=t%B)。
  • 除法÷高精度：本质“重复减法”，用 cmp/sub/cpy 函数与临时数组 T 移位对齐，商每位=可减次数。
所有高精度实现均围绕“逆序存储+统一进位+去前导零”。进位必须单独遍历处理，不能在乘除循环中实时进位，否则影响后续位。

九、经典递推专题：过河卒

小卒从 (0,0) 出发，只能向下/向右到 (N,M)，避开对方马及其 8 个“日”字控制点(共 9 个禁点)。

无障碍递推：f(i,j) = f(i-1,j) + f(i,j-1)(来自上方或左方)。边界：第一行/列路径数均为 1。本质是组合数学 C(i+j, i)。

带障碍处理：将马位及其 8 控制点标记为 0 并跳过；边界修正——i=0 时 a[i][j]=a[i][j-1]，j=0 时 a[i][j]=a[i-1][j]，避免 0 值污染。最终答案 a[N][M](为 0 即无路径)。

注意坐标系转换：数学 (x,y) 与数组 a[行][列] 的行列映射；控制点坐标如 P1=(X+2, Y−1)，标记前判断是否在 [0,N]×[0,M] 内防越界。
